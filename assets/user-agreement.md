## 一、协议范围与服务性质

1. 本协议适用于你对本应用客户端、其界面和由客户端提供的相关功能的使用。
2. 本应用通过饭否公开的接口、授权机制和相关页面提供服务。饭否账号、饭否平台上的内容、饭否接口以及饭否平台规则由饭否运营和管理。本应用不是饭否的官方应用，也不代表饭否作出任何承诺。

   - [饭否用户协议](https://help.fanfou.com/agreement.html)
   - [饭否隐私条款](https://help.fanfou.com/privacy.html)
4. 本应用可能随饭否接口、平台规则、操作系统或第三方依赖的变化而调整功能。

## 二、账号登录与授权

1. 你可以通过饭否 OAuth 1.0a 网页授权登录本应用。
2. 你应当使用本人合法控制的饭否账号登录，并确保登录、授权和使用行为符合饭否规则及适用法律。
3. 你应妥善保管设备、账号和授权凭据。通过你的设备或已登录会话完成的操作，通常会被视为由你发起。发现账号、设备或授权凭据存在异常时，应立即通过饭否提供的方式处理。
4. 你可以在本应用中退出账号或移除本地保存的账号会话。退出本应用不会注销饭否账号，也不会撤回饭否服务侧已经授予的权限；如需撤回授权或处理账号安全问题，应使用饭否提供的账号管理功能。
5. 当饭否拒绝授权、撤销授权、限制账号或调整接口权限时，本应用可能无法继续提供全部或部分功能。

## 三、可用功能

在饭否接口和账号权限允许的范围内，本应用可能提供以下功能：

- 浏览首页、提到、发现、搜索、个人主页、关注、粉丝、关注申请、收藏等内容；
- 发布、回复和转发消息；
- 选择、校验、压缩或转码图片并上传到饭否；
- 查看和发送私信；
- 关注或取消关注用户；
- 收藏或取消收藏消息；
- 拉黑、取消拉黑以及查看黑名单；
- 管理多个已授权的饭否账号和应用外观设置。

具体功能、名称、入口和可用范围可能因饭否接口、账号权限、设备系统或版本变化而不同。
