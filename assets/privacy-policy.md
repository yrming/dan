「旦」（以下简称“本应用”）是一个访问饭否服务的第三方客户端。本隐私政策说明本应用在你使用相关功能时如何处理信息。请在使用本应用前阅读本政策；如果你不同意本政策，请停止使用本应用。

## 一、适用范围

1. 本政策适用于本应用客户端对信息的收集、使用、存储和传输。
2. 本政策不适用于饭否直接运营的服务、饭否网站、饭否服务器或你通过外部链接访问的其他服务。饭否如何处理账号和平台数据，应以饭否公布的政策为准：
   - [饭否用户协议](https://help.fanfou.com/agreement.html)
   - [饭否隐私条款](https://help.fanfou.com/privacy.html)
3. 本应用是饭否第三方客户端。截至本政策生效日，没有证据表明本应用运营独立的内容社区、广告系统或第三方行为分析服务；本政策只描述本应用当前实际实现的处理方式。功能或架构发生变化时，本政策会相应更新。

## 二、本应用处理的信息

### 1. 登录与授权信息

根据你选择的登录方式，本应用会处理完成饭否登录或授权所需的信息：

- OAuth 1.0a 授权流程中的请求令牌、访问令牌、令牌密钥、回调地址和授权结果；
- 饭否返回的账号标识、用户名、显示名称、头像、简介、位置、主页地址、账号状态、关注关系、计数和其他账号资料。

### 2. 账号资料和社交关系

当你浏览个人主页、关注、粉丝、关注申请、黑名单、收藏或相关列表时，本应用会从饭否读取并在内存中使用相关用户资料、消息、关注关系、收藏状态和拉黑状态，以展示页面和完成你的操作。

### 3. 你主动提交的内容

当你使用发布、回复、转发、私信、搜索或其他输入功能时，本应用会处理你主动输入的文字、搜索关键词、链接、回复对象、转发对象和收件人，并将完成对应功能所需的信息发送至饭否 API。

### 4. 图片和临时文件

当你选择图片上传时，本应用可能处理图片文件的文件名、格式、文件签名、大小、尺寸和图像内容，用于校验、压缩、转码和上传。超限图片可能被转换为 JPEG、调整尺寸或重新编码；处理过程中产生的临时上传文件会在上传成功或失败后按应用流程清理。

### 5. 应用设置和本地会话

本应用会在设备本地保存你主动设置的外观偏好，例如主题、字体大小和图片显示方式；同时会保存已登录账号的必要资料和 OAuth 会话，用于恢复登录状态、切换账号和发起饭否 API 请求。你应妥善保护设备和已登录会话，避免在不受信任的设备上使用本应用。

### 6. 网络和错误信息

本应用会向饭否官方 API 和 OAuth 服务发起请求。生产环境请求使用 HTTPS，并限制到饭否官方 `api.fanfou.com` 和 `fanfou.com` 主机。饭否返回的接口错误信息可能被解析后显示在页面反馈或临时提示中，以帮助你了解操作失败原因。

## 三、处理信息的目的

本应用处理上述信息仅用于：

- 完成登录、授权、账号切换和会话恢复；
- 请求并展示首页、提到、发现、搜索、个人主页、关注、粉丝、收藏、黑名单和其他饭否内容；
- 发布、回复、转发消息，发送和展示私信；
- 完成关注、收藏、拉黑及取消对应操作；
- 选择、处理和上传图片；
- 保存你的外观设置和提供必要的故障反馈；
- 保障请求安全、处理接口错误和维持应用正常运行。

本应用不会为了广告画像或与当前功能无关的目的，主动扩大收集范围。

## 四、信息的传输和共享

1. 本应用会把完成饭否功能所必需的信息发送给饭否，包括登录授权信息、消息和私信内容、搜索词、收件人、图片以及你主动执行的关注、收藏、拉黑等操作。饭否收到信息后如何使用和保存，以饭否的政策和规则为准。
2. 本应用不会将账号令牌、私信或其他个人信息出售给第三方。除以下情形外，本应用不主动向无关第三方提供这些信息：
   - 你主动使用系统分享、外部链接、浏览器或其他第三方能力；
   - 为完成设备系统或应用商店提供的必要功能而发生的系统级处理；
   - 依据法律法规、司法机关或行政机关的合法要求。
3. 本应用当前没有已知的广告 SDK、独立分析 SDK 或自建业务服务器。若未来引入新的处理者、统计服务或其他信息共享场景，会在更新本政策后说明其用途和范围。

## 五、信息的保存、删除和控制

1. 账号资料、OAuth 会话和应用设置会保存在你的设备上，保存时间取决于你是否继续登录和使用本应用。
2. 你可以在本应用中退出账号、切换账号或移除账号，以删除本应用本地保存的相应会话和账号资料。你也可以清除应用数据或卸载应用；具体效果受操作系统实现影响。
3. 删除本应用本地数据不会删除已经发送到饭否的消息、私信、图片、收藏、关注关系或其他饭否平台数据。需要删除饭否平台数据时，请通过饭否提供的功能和渠道操作。
4. 本应用不会因为你退出账号而代替你撤销饭否授权。你可以在饭否账号设置或饭否提供的其他渠道管理授权。
5. 在法律要求的保存期限届满、处理目的完成或你依法提出有效请求后，本应用会在可控制范围内删除或去标识化相关本地信息；已经由饭否保存的信息不在本应用可直接控制的范围内。

## 六、信息安全

1. 本应用使用 HTTPS 与饭否官方服务通信，并对 OAuth 回调目标、请求令牌和授权结果进行必要校验。
2. 请使用设备锁屏、系统更新、可信网络和官方安全功能保护设备，不要在已被破解或不受信任的设备上登录重要账号。
3. 没有任何传输或存储方式能够保证绝对安全。如发现账号或本地会话异常，请立即退出本应用并通过饭否官方渠道撤销授权或处理账号安全问题。

## 七、未成年人信息

如果你未满法定成年年龄，应在监护人同意和指导下使用本应用，并确保你的使用符合饭否的年龄要求和适用法律。监护人如发现未成年人未经同意使用本应用或提交信息，请通过本政策所列联系方式联系我们。

## 八、你的权利

在适用法律允许的范围内，你可以了解本应用处理的信息、要求更正不准确的信息、删除本应用本地保存的信息、撤回继续使用本应用的意愿，或就隐私处理提出问题和投诉。由于本应用是饭否第三方客户端，饭否平台侧账号、内容和授权数据的访问、更正、删除或撤回，应直接向饭否提出请求。

如需行使与本应用本地数据有关的权利，请提供足以定位问题的说明，但不要在邮件或反馈中发送 OAuth 令牌、令牌密钥或其他不必要的敏感信息。

## 九、政策更新

当功能、数据处理方式、法律要求或运营主体发生变化时，本应用可能更新本政策。更新后的版本会在本应用或项目发布渠道中公布，并标明更新日期。继续使用本应用表示你接受更新后的政策；如果你不同意更新内容，请停止使用本应用并清除本地会话。
